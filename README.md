  # **Haunted Corp**

  ## **DESCRIPTION**
  Haunted Corp is supposed to simulate what it would be like if a group of supernatural monsters created a haunted house and ran it like a bussiness complete with analytics.

## **KEY FEATURES:**
- Custom API using Prisma, Express, and PortgeSQL
- Interactive overworld
- Optional quick navigation
- Data seed generator
- Data deletion terminal command
- Charts that display haunted house data
- Employee cards for each monster
- Secratary that gives general overview of all facilities

## **HOW TO USE (Visual Studio Code)**
Use npm run seed inside the backend folder to generate the data and then use npm run dev in both the frontend and backend folder in order to properly start the program. Lastly explore and walk around.
